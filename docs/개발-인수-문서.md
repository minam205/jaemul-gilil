# 재물 길일 나침반 — 개발 인수 문서

작성일 2026-11-07 · 담당 이영호(leeyh@zkrypto.com) · 저장소 https://github.com/minam205/jaemul-gilil

이 문서는 이 서비스를 이어받는 개발자가 **처음 30분에 읽는 것**입니다. 코드는 `index.html`(메인)과 `v2/index.html`(도장첩 버전) 두 파일에 전부 들어 있고, 빌드 도구·서버·데이터베이스가 없습니다.

---

## 1. 이 서비스가 하는 일 (한 줄)

생년월일시로 사주를 세워, **이번 회차 로또를 어느 요일에, 어느 방향 판매점에서 사면 좋은지** 알려 줍니다. 타겟은 사주·미신을 좋아하는 60~70대 로또 구매자입니다.

약속하지 않는 것: 당첨, 확률, 예측. 화면 어디에도 이 말을 쓰지 않습니다(복권 광고 규제 + 소비자 기만 이슈).

## 3. 화면 흐름 (두 버전 공통)

```
입력(생년월일·시진) → 회차 목록(일~토, 등급 인장) → 날짜 상세(윤도 나침반·판매점·할 일·근거) → 기록/도장첩
```

- 화면 전환은 `show(view)` 한 함수로 `hidden` 토글. 주소 해시(`#input #week #day #record`)로 뒤로가기 지원.
- 주간은 **로또 주기(일요일~토요일 추첨)**. 회차 번호 = 2002-12-07(1회) 기준 토요일 수 계산 `roundOf(sunJ)`.
- 토요일 20:00 이후는 "판매 끝"으로 보고 답 카드가 다음 회차를 가리킴.

## 4. 계산 규칙 (가장 중요한 부분)

### 4-1. 사주 세우기 `saju(y,m,d,hh,mm,solar,yaja)`
- 날짜 → 율리우스일(`jdn`). 일진 = `(J+49) mod 60` (갑자 = 0).
- 년주·월주는 **절기 기준**: 태양 황경을 Meeus 저정밀식(`sunLon`)으로 구해 입춘(315°) 전이면 전년, 월지는 황경 30° 단위. 외부 만세력 API 없음. 오차 수 분 수준.
- 옵션 `solar`: 서울 경도 보정 −30분. 옵션 `yaja`: 23시 이후 출생을 당일 일주로(야자시). 둘 다 기본 ON.
- 시진 입력은 12지지 선택 + "모름"(12:00 처리).
- 신강·신약: 일간과 같은 오행·낳아 주는 오행이 전체 7점(월지 2점) 중 차지하는 비율. <45% 신약, ≥55% 신강. **간이 판정**이라 전문 감정과 다를 수 있음.
- 검증 완료: 2000-01-01(무오일), 1984년 입춘 전후 년·월주 전환, 1979-11-18 23:55(기미 을해 기축 병자).

### 4-2. 날짜 점수 `scoreDay(me, J)` — 로또(횡재) 기준
| 규칙 | 점수 |
|---|---|
| 일진 천간이 내 **편재**(재성 중 음양 같음) | +4 |
| 일진 천간이 내 **정재** | +1.5 |
| 일진 지지 정기가 편재 / 정재 | +4 / +1.5 |
| 천을귀인 지지 | +2 |
| 천간합(갑기·을경·병신·정임·무계) | +2 |
| 지지 육합 / 삼합(일지 기준) | +2 / +1.5 |
| 역마(일지 삼합국 기준) | +1.5 |
| 일지 충 / 년지 충 | −3 / −2 |
| 공망(일주 순중 공망) | −2 |
| 편관(천간 극, 음양 같음) | −1.5 |
| 신약이면 재성 점수 ×0.6, 비겁·인성 날 +1 | 조정 |

등급: ≥4 대길 · ≥2 길 · >−2 평 · 그 외 흉. 가중치 숫자는 전통 규칙이 아니라 **이 앱이 정한 값**입니다.

### 4-3. 방위
- 재신방(돈 일 보는 쪽): 일진 천간 기준 황력 표 — 갑을 동북 · 병정 서남 · 무기 북 · 경신 동 · 임계 남.
- 희신방(사람 만나는 쪽): 갑기 동북 · 을경 서북 · 병신 서남 · 정임 남 · 무계 동남.
- 고정 유리 방위: 내 재성 오행의 방위(목 동 · 화 남 · 토 중앙 · 금 서 · 수 북).
- 윤도 그림 `drawCompass()`: 안쪽부터 팔괘(후천) → 24방위 → 24절기 → 72분금. 금색 쐐기 = 재신방(±22.5°).

## 5. 판매점 찾기 (카카오)
- 버튼을 누를 때만 SDK 로드(`loadKakao`). 키: `index.html`의 `KAKAO_KEY`. 카카오 개발자 콘솔 **"입지 분석 스코어맵" 앱의 JavaScript 키**(계정당 한 앱만 무료 할당이라 기존 앱을 씀). Web 도메인 `https://minam205.github.io` 등록됨.
- 검색 중심을 **그날 방향으로 1km 옮긴 지점**으로 잡아 키워드 "로또", "복권" 각 3페이지(45곳) + 내 위치 800m "로또". 거리는 내 위치 기준 재계산, 2.5km 안만.
- 방위각 ±22.5° 안이면 "그 방향 판매점"(최대 5), 아니면 "방향은 다르지만 가까운 곳"(2).
- 위치는 기기 안에서만 쓰고 저장하지 않음 → 위치기반서비스 신고 대상 아님(서버로 보내기 시작하면 신고 필요, 1인 창업자는 1개월 유예).

## 6. 저장 데이터 (localStorage)
| 키 | 내용 |
|---|---|
| `jaemul2` | 생년월일시 `{y,m,d,h(시진 index),n(이름),so,ya}` |
| `jaemul_rec` | 구매 기록 `{ [J]: {J, bought, score, grade, dir, gi(일진 index), result(none/r5/r4/r3/null), at} }` |
| `jaemul_open` | (v2 이전 가챠 버전 흔적, 현재 미사용) |

백업 포맷(v2 "저장 글자"): `JAEMUL1.` + base64(JSON `{v:1, birth, rec}`). 불러올 때 `at` 기준으로 합침.

## 7. 60~70대 UI 규칙 (지켜야 할 것)
- 본문 20px, 버튼 60px, 한지 바탕 단일 테마(다크모드 없음).
- 등급은 **대길·길·평·흉 한글 인장 + 점수**. 한자 단독 표기 금지.
- 사주 용어(지지 글자, 십신)는 화면 앞에 두지 않고 달력 날짜·방향·행동으로 바꿔 보여 줌. 간지(신사일)는 보여도 됨(이 세대에겐 신뢰 근거).
- 방향은 반드시 "기준점(지금 있는 곳) → 각도 → 확인법(휴대폰 나침반) → 없을 때 대안" 세트로.
- 이모지 금지. 외래어(캘린더→달력, 기기→휴대폰) 금지.
- 문구 가이드: 프로젝트 문서 「재물길일-마케팅-메시지-가이드」. 핵심은 "꿈 → 내 것 → 오늘 할 일" 세 줄, 당첨 약속 금지.

## 8. 알려진 한계 · 다음 할 일
1. **음력 없음.** 이 세대는 음력 생일이 많음. 한국천문연구원 음양력 API(공공데이터포털) 붙여야 함. 중국력 테이블로 대체하면 드물게 하루 틀림.
2. 신강·신약 간이 판정 → 재성 반영률(100%/60%)이 바뀌므로 영향이 큼.
3. 야자시 옵션에 따라 일주가 바뀌면 길일이 통째로 달라짐(23시대 출생자).
4. 기록은 기기 안에만. 동기화·개인별 푸시 알림은 P4(서버) — 개인정보처리방침·위치정보 신고가 같이 옴.
5. 두 버전(메인·v2)은 도장첩만 다름. 2주 써 보고 괜찮으면 메인에 합치고 v2 삭제.
6. 네이티브 앱(스토어 배포)이 필요하면 PWA를 그대로 감싸는 방식(안드로이드 TWA, iOS Capacitor)이 가장 싸다. 코드 변경 거의 없음.

## 9. 로컬에서 돌려 보기
```
git clone https://github.com/minam205/jaemul-gilil
cd jaemul-gilil && python3 -m http.server 8080
# http://localhost:8080  (판매점 찾기는 카카오 도메인 제한 때문에 localhost에서 안 됨 → 콘솔에 http://localhost:8080 추가하면 됨)
```
의존성 없음. 수정 → `main`에 push → 1~2분 뒤 사이트 반영. `sw.js`의 `CACHE` 이름을 올려야 설치된 앱이 새 파일을 받음(지금 `jaemul-v18`).
